# PricePulse (网购商品实时价格监控与比价平台) — 产品需求文档 (PRD)

> **文档状态**：持续迭代中  
> **目标平台**：京东 (JD.com)、淘宝/天猫 (Taobao/Tmall)  
> **通知渠道**：飞书 (Feishu) 自定义机器人 Webhook

---

## 1. 项目背景与定位

本项目旨在构建一个自托管的**网购商品实时盯盘、价格走势追踪与全网自动比价平台**。用户只需复制京东或淘宝的商品链接并粘贴到系统中，即可实时获取当前价格、回溯历史价格走势、追踪史低价，并在商品降价、下架或平台登录态失效时通过飞书 Webhook 第一时间收到推送通知。同时支持跨店铺、跨平台的同款商品自动比价，辅助用户以最优价格完成购买决策。

---

## 2. 核心功能需求

### 2.1 商品链接添加与实时价格抓取
- **支持平台**：
  - 京东（JD.com）
  - 淘宝 / 天猫（Taobao / Tmall）
- **交互流程**：
  - 用户直接复制商品分享链接或浏览器地址栏链接（支持短链解析与清洗，自动提取商品 SKU / Item ID）。
  - 粘贴到平台网页输入框后，系统立即触发抓取并在页面内展示商品基础信息（商品标题、主图、店铺名称、当前实时价格体系等）。
- **多维价格与优惠信息抓取（核心）**：
  - **页面标价 / 日常售价**：商品当前的未优惠标价。
  - **优惠券与促销明细**：自动识别并抓取商品可领用的**店铺优惠券、平台满减券、跨店满减、限时直降、PLUS / 88VIP 会员折上折**等权益信息，展示领券门槛与减免面额（如：`满 1000 减 150`、`店铺立减 50`）。
  - **国家补贴（国补）价格识别**：自动检测商品是否支持**政府消费补贴 / 国家以旧换新补贴（国补）**（如家电、数码 3C 类目 15% / 20% 国补标识），抓取或折算**国补立减金额**与**国补后到手价**。
  - **预估最低到手价**：综合优惠券、满减与国补后，自动计算出用户实际需要支付的**最优到手价**，在列表中显著高亮。
- **监控频率配置**：
  - 支持全局默认轮询间隔与单商品自定义监控频率（如高优盯盘商品更高频抓取）。

### 2.2 历史价格抓取与价格走势图
- **历史价格初始化**：
  - 添加商品时，优先尝试从第三方历史价格数据源或接口抓取该商品的过往历史价格数据并导入系统。
  - **降级策略**：若无法获取到历史价格数据，则直接以**当前抓取到的价格作为起点**，开启持续的实时价格监控与记录。
- **商品详情与走势可视化**：
  - 点击进入单个商品详情页后，展示交互式**价格走势折线图**（支持按时间维度筛选：如近 7 天、30 天、90 天、全部；支持同时对比「页面标价」、「券后价」与「国补后到手价」走势）。
  - 核心价格指标高亮展示：
    - **当前标价 / 券后价 / 国补后价格**（清晰拆解价格构成）
    - **当前可用优惠券列表 & 国补资格标签**
    - **历史最低价 / 史低价**（All-Time Low，区分常规史低与叠加国补/大促神券后的史低）及出现日期
    - **历史最高价**（All-Time High）
    - **监控起始价**与**累计涨跌幅**

### 2.3 平台登录态管理（扫码登录与保活）
由于京东、淘宝部分商品详情、专属优惠价及比价搜索必须处于登录状态下才能正常访问，系统需内置可视化的登录态管理模块：
- **网页端获取登录二维码 / 登录链接**：
  - 系统后台通过无头浏览器或协议接口抓取京东、淘宝官方登录链接或登录二维码，并实时渲染在平台网页设置页中。
  - 用户直接使用京东 App / 手机淘宝扫码完成登录。
- **登录态持久化与保活**：
  - 登录成功后，自动提取并安全保存 Cookie / Token / Session 状态至服务端，供后续定时抓取任务复用。
  - 支持定期心跳检测以验证登录态是否有效，并在可能的情况下刷新保活。
- **失效告警**：
  - 一旦检测到京东或淘宝登录态过期/失效（如触发登录重定向或风控拦截），立即更新后台状态并通过飞书推送告警，提示用户重新扫码。

### 2.4 飞书 Webhook 实时消息推送
通过接入飞书群自定义机器人 Webhook（支持富文本卡片消息），在以下关键事件触发时进行实时推送：

1. **商品降价 / 新放出神券 / 开启国补推送**：
   - **触发条件**：监控商品的最新抓取价格（页面价、券后价或国补后价格）低于上次记录价格，或检测到新发放的大额优惠券 / 新开启国补资格。
   - **推送内容**：
     - 商品名称、图片及直达购买链接
     - **降价前价格** vs **当前最新价格**（明确标注**页面价**、**券后到手价**、**国补后到手价**）
     - **优惠明细拆解**：当前可领优惠券（面额/门槛）、是否支持国补及国补立减金额
     - **下降金额**（如：`直降 ¥50.00` 或 `叠加国补再降 ¥300.00`）与**降幅比例**（如：`-12.5%`）
     - **史低价对比**（当前到手价是否为最新史低价，或距离史低价还差多少）
2. **商品下架 / 缺货推送**：
   - **触发条件**：监控到商品页面下架、无货、停止销售或链接失效。
   - **推送内容**：提示商品已下架/无货，附带最后一次有效价格及同款比价建议链接。
3. **平台登录态失效推送**：
   - **触发条件**：京东或淘宝 Cookie / 登录态过期、触发滑块验证或需重新登录。
   - **推送内容**：指明失效的平台（京东 / 淘宝），并附带本平台后台的快捷扫码管理入口链接。

### 2.5 全网实时自动比价
- **同款商品跨店 / 跨平台检索**：
  - 针对当前监控的商品（基于商品标准名称、品牌型号、核心规格参数或条码），自动在**同平台其他店铺**以及**另一网购平台（京东 ↔ 淘宝）**进行实时检索。
- **比价结果聚合展示**：
  - 在商品详情页展示全网比价列表，包含：平台标识、店铺名称（自营/旗舰店/普通店标识）、页面售价、**有无优惠券及券后价**、**是否支持国补及国补后价格**、销量/评价参考及直达链接。
  - 自动按**最终预估到手价（含券 + 国补）**排序并标记全网最低价渠道，当其他平台/店铺出现明显低于当前监控商品的价格时，可在页面高亮提醒或附带在飞书降价卡片中。

## 3. 迭代路线图 (Roadmap)

### Phase 1：基础框架与核心监控闭环 (MVP)
- [ ] 前后端项目脚手架搭建与数据库表结构设计（商品表、价格与优惠历史流水表、平台凭证表、通知配置表）
- [ ] 京东 / 淘宝商品链接解析器（支持分享短链、PC/移动端链接提取标准商品 ID）
- [ ] 网页端扫码获取与保存京东、淘宝登录态（Cookie / Session 持久化与状态检测）
- [ ] 单商品实时价格、**优惠券信息**与**国家补贴（国补）价格**抓取及定时轮询任务调度（无历史数据时从当前价格开始记录）
- [ ] 飞书 Webhook 机器人集成（支持含券后价/国补价明细的降价对比卡片、商品下架提醒、登录态失效提醒）

### Phase 2：历史价格回溯与可视化走势面板
- [ ] 历史价格数据补全模块（对接历史价格数据源，失败时平滑降级为实时累积）
- [ ] 商品详情页开发：交互式价格走势图、史低价/最高价指标卡片、历史变价时间轴
- [ ] 支持设置单商品"目标心愿价"及"仅史低通知"等精细化推送策略

### Phase 3：全网自动比价与智能匹配
- [ ] 基于商品名与规格的跨店铺、跨平台（京东 ↔ 淘宝）实时搜索模块
- [ ] 同款商品相似度清洗与过滤（剔除配件、引流低价SKU等干扰项）
- [ ] 商品详情页全网比价看板与跨平台更低价发现提醒

### Phase 4：稳定性增强与长期演进
- [ ] 反爬风控应对策略优化（请求频率自适应抖动、浏览器指纹与代理池可选支持）
- [ ] 优惠券、满减凑单与到手价折算支持
- [ ] 多飞书 Webhook 群组/多用户订阅管理与每日/每周盯盘汇总日报
